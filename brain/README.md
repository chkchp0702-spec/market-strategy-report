# 🧠 시황 두뇌 — 매시간 쌓는 지식·통찰 (10/9 사용자: "수익률 개선이 제일 중요해. 한 시간에 한 번 피드와 전략·시황·경제 자료를 모아 분석·검토하고 그 통찰을 쌓아가, 매일 아침 시황리포트와 포트에 반영해 시장을 이기는 포트를 만들어")

매시간 예약 작업(「시황 두뇌 — 매시간 검토」)이 채우고, 매일 아침 시황리포트가 읽는다.

| 파일 | 내용 |
|---|---|
| `state.json` | 지금 생각의 요약 (앱 📰 피드 탭 「🧠 지금 생각」에 보임). theses(논지·확신도·근거·깨지는 조건), watch(지켜볼 것), port_ideas(포트 비중·킥 제안), last_review, **kr_today**(10/19 A10/19-3: 오늘 코스피 종가 방향 한 낱말 — 「오름 / 내림 / 중립」. 장 시작 전 생각을 적을 때 같이 적는다. 앱 🔮 채점 카드가 매일 종가로 채점해 🎲 시장확률·🧠 두뇌 국면과 나란히 보여 줌 — 안 적은 날은 채점 안 함) |
| `insights.md` | 쌓이는 통찰 장부 — 확인된 패턴·교훈(무엇이 맞았고 틀렸나). 오래된 건 합치고 줄인다. |
| `log/YYYY-MM-DD.md` | 시간별 검토 기록 (새 글 몇 개, 중요한 것, 바뀐 생각) |

원칙
- 숫자는 출처(피드 id 또는 기사 URL)와 함께. 확인 안 된 건 "미확인".
- 논지는 맞았는지 나중에 채점한다(state.json theses[].check). 틀린 논지는 지우지 말고 insights.md 「틀린 것에서 배운 것」으로 옮긴다.
- 포트 제안은 RULES 1-E 의 한도 안에서만. 실제 비중 변경은 아침 리포트가 한다(하루 한 번, 근거 숫자와 함께).
- 🌏 **해외 상품 점검 (RULES 1-I, 10/10)**: 매시간 market/peers.json 과 market/port.json 의 hold[].pick_vs 를 본다. ① 포트에 담긴 해외 종목(picks)이 「약함」·50일선 이탈·원래 미국 상품 대비 −5%p 이하로 가면 port_ideas 에 「○○ 칸 상품 ○○ 빼기 — 근거」 ② 「과열 — 눌림 대기」 종목(예: 아오스캉테크 002913.SZ)이 식어 「편입 후보」가 되면 port_ideas 에 「○○ 칸에 ○○ 넣기 — 근거」. 실제 교체는 아침 리포트가 한다. 해외 종목 소식(실적·수주·규제)도 웹에서 찾아 ai_found 에.
- 📰 **모든 출처를 빠짐없이 (10/10 사용자: "블룸버그뿐만 아니라 모든 걸 다")**: my_feed.json 에 블로그·텔레그램 13곳 + 뉴스 50곳(블룸버그·로이터·WSJ·FT·마켓워치·배런스·시킹알파·니케이아시아·SCMP·차이신·연준·ECB·EIA·연합·인포맥스·이데일리·서울경제·머니투데이·조선비즈·뉴스핌·더벨·일본·홍콩 구글뉴스 등)이 15분마다 들어온다. 매시간 새 글을 출처 가리지 않고 전부 훑고, 피드 밖은 WebSearch 로 더 찾는다. 유료 기사(블룸버그·WSJ·FT·배런스)는 제목·요약만 있으니 숫자는 무료 기사로 한 번 더 확인해 쓴다. insights.md 「출처별 신뢰도」에 출처마다 맞았나/틀렸나를 쌓는다.
- 🔧 **자가 업그레이드 (10/10)**: 매일 저녁 예약 작업 「자가 업그레이드」가 ideas.md·성적표를 보고 실제 코드·규칙을 하루 최대 2개 고친다(기록: brain/upgrades.md). 두뇌는 고칠 거리를 ideas.md 에 숫자와 함께 남기면 된다 — 「무엇이 수익을 깎고 있나」가 가장 좋은 재료.
- 🫀 **심리 계기판 (10/19 사용자 「심리·선물·옵션·신용 물량에서 심리 흐름을 봐」)**: 매시간 market/sentiment.json 을 읽는다 — VIX·VIX3M 역전, SPY 풋/콜, 외가 풋 프리미엄, 외국인 선물 5일 누적, 신용잔고. 규칙 R1~R5 와 쓰는 법은 brain/sentiment_lab.md(결과 보기 전 등록 · 그림자). log 「시장 한 줄」 옆에 `🫀 line` 을 붙이고, **R1x(공포 해소 첫날)는 20년 검증 통과 → 우리 신호로 인정: 그날 SPY·QQQ bets 가능(5일·손절 −3%, sig 「🫀R1x」).** R1·R7 켜지면 새 bets 는 3일·목표 절반. 한국 외국인 선물은 역발상이 아니라 추세(5분위 검증) — 선물 투매(R7)를 「곧 반등」으로 읽지 않는다. R3·R4 동시면 한국 논지 깨짐 후보로 check 에. 겹친 bets 의 sig 에 「· 🫀R4」처럼 붙여 따로 센다. null 이면 「🫀 미수집」.
- 🧾 **bets 채점은 시세가 되는 쪽이 한다 (10/10 자가 업그레이드 — 이 줄이 예약 작업 글의 「한도 10 넘으면 닫는다」보다 우선)**: 두뇌 세션은 야후 시세가 막혀 entry 를 못 정한다. 그래서 10/9~10 bets 19개 중 9개가 「미진입 ±0」으로 채점 없이 닫혔다(0승 0패). 이제 ① entry 를 모르면 숫자를 지어내지 말고 `entry: null` + `entry_rule: "10/12 시가"`(날짜·시가/종가)만 적고 status 는 **「대기」** ② **「대기」는 열린 한도 10 에 세지 않고, 한도 때문에 닫지 않는다** — 한도는 status 「열림」만 센다. 한도가 차면 새 bet 을 만들지 말고 기존 bet 근거를 보탠다(주말·휴장엔 특히) ③ GitHub Actions 가 매시간 `src/bets_score.py` → **market/bets_score.json** 에 entry(시가/종가)·진행·이김/짐/기한을 계산한다. 매 검토 때 이 파일을 읽어 bets 의 entry·status(대기→열림→닫힘)·res 와 scorecard.bets(made·win·loss·avg)를 그대로 옮긴다. 손으로 다시 판정하지 않는다.

- ⭐ **피드 중요 표시 (10/21 사용자 「중요한 뉴스·글은 색깔이나 중요 표시로 — 가독성」)**: 매시간 새 글을 읽은 뒤 feeds/hot.json 의 items 에 `"<my_feed id>": {"lv": 2|1, "why": "한 줄(어느 칸·가설·bet 과 이어지나)", "at": "YYYY-MM-DD HH:MM"}` 를 더한다. **아끼고 아낀다(10/21 사용자 「웬만하면 핵심이래 — 정말 정말 중요한 것만」)**: lv2 🔴 핵심 = 하루 0~3개, 대부분 시간은 0개 — 연준·한은 깜짝, 지수 −3%↓ 급변, 보유 칸·킥 종목 직격, 핵심 가설을 뒤집는 숫자만. lv1 🟡 주목 = 시간당 0~3개, 그다음으로 중요한 것만. 애매하면 표시하지 않는다. 같은 사건 기사가 여럿이면 가장 좋은 1개만. 7일 지난 id·my_feed 에 없는 id 는 지운다. 앱 📰 피드가 색 테두리·이유 한 줄·맨 위 「🔴 지금 꼭 볼 글」·⭐ 중요 칩으로 보여 준다(바로 반영).

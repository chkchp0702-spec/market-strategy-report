# 🧠 시황 두뇌 — 매시간 쌓는 지식·통찰 (10/9 사용자: "수익률 개선이 제일 중요해. 한 시간에 한 번 피드와 전략·시황·경제 자료를 모아 분석·검토하고 그 통찰을 쌓아가, 매일 아침 시황리포트와 포트에 반영해 시장을 이기는 포트를 만들어")

매시간 예약 작업(「시황 두뇌 — 매시간 검토」)이 채우고, 매일 아침 시황리포트가 읽는다.

| 파일 | 내용 |
|---|---|
| `state.json` | 지금 생각의 요약 (앱 📰 피드 탭 「🧠 지금 생각」에 보임). theses(논지·확신도·근거·깨지는 조건), watch(지켜볼 것), port_ideas(포트 비중·킥 제안), last_review |
| `insights.md` | 쌓이는 통찰 장부 — 확인된 패턴·교훈(무엇이 맞았고 틀렸나). 오래된 건 합치고 줄인다. |
| `log/YYYY-MM-DD.md` | 시간별 검토 기록 (새 글 몇 개, 중요한 것, 바뀐 생각) |

원칙
- 숫자는 출처(피드 id 또는 기사 URL)와 함께. 확인 안 된 건 "미확인".
- 논지는 맞았는지 나중에 채점한다(state.json theses[].check). 틀린 논지는 지우지 말고 insights.md 「틀린 것에서 배운 것」으로 옮긴다.
- 포트 제안은 RULES 1-E 의 한도 안에서만. 실제 비중 변경은 아침 리포트가 한다(하루 한 번, 근거 숫자와 함께).
- 🌏 **해외 상품 점검 (RULES 1-I, 10/10)**: 매시간 market/peers.json 과 market/port.json 의 hold[].pick_vs 를 본다. ① 포트에 담긴 해외 종목(picks)이 「약함」·50일선 이탈·원래 미국 상품 대비 −5%p 이하로 가면 port_ideas 에 「○○ 칸 상품 ○○ 빼기 — 근거」 ② 「과열 — 눌림 대기」 종목(예: 아오스캉테크 002913.SZ)이 식어 「편입 후보」가 되면 port_ideas 에 「○○ 칸에 ○○ 넣기 — 근거」. 실제 교체는 아침 리포트가 한다. 해외 종목 소식(실적·수주·규제)도 웹에서 찾아 ai_found 에.
- 📰 **블룸버그 우선 (10/10)**: my_feed.json 의 bbg_mkt·bbg_tech·bbg_econ·gn_bbg·gn_kr_bbg 가 블룸버그다(제목·요약). 매시간 새 블룸버그 기사를 **빠짐없이** 훑고, 포트 칸·킥 종목·해외 상품과 이어지는 건 웹에서 같은 내용을 다룬 무료 기사(로이터·CNBC·한국 언론)로 숫자를 확인해 쓴다.
- 🔧 **자가 업그레이드 (10/10)**: 매일 저녁 예약 작업 「자가 업그레이드」가 ideas.md·성적표를 보고 실제 코드·규칙을 하루 최대 2개 고친다(기록: brain/upgrades.md). 두뇌는 고칠 거리를 ideas.md 에 숫자와 함께 남기면 된다 — 「무엇이 수익을 깎고 있나」가 가장 좋은 재료.

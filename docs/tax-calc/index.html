계산 기준
  • A 의제배당: (합병대가 − 취득가액)을 배당소득으로 봄. 다른 이자·배당과 합쳐 연 2,000만 원 이하면 15.4% 분리과세, 넘으면 다른 종합소득과 합산해 누진세율(6~45%, 지방세 포함 6.6~49.5%)로 계산함. 비교과세(최소 14%) 반영. 수수료는 차감하지 않음.
  • B 양도세: (합병대가 − 취득가액 − 수수료 + 다른 해외주식 손익 − 기본공제) × 22%.
  • A와 B는 서로 대신하는 가정임. 실제로 어느 쪽인지는 합병 구조(테슬라 존속 vs 소멸)와 국세청 해석으로 정해짐.
  • 외국납부세액은 입력액을 A 증가 세액 한도 안에서 단순 차감함. 실제 공제 한도·증빙은 별도 확인 필요.
  • 건강보험료, 지방소득세 외 부가세목, 배당세액공제는 반영하지 않음. 이 계산기는 세무신고서가 아니며 세무·법률 자문이 아님. 실행 전 세무사 확인 필수.
